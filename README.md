# BGplayer

Видеоплеер для Android (7.0+), который:

- играет звук при выключенном экране и в фоне (уведомление с кнопками);
- повторяет видео по кругу (кнопка «Повтор», по умолчанию включён);
- останавливается по таймеру сна (15/30/45/60/90 мин или своё значение; последние 10 с звук плавно затухает, затем пауза);
- переходит по главам видео с кнопок наушников.

## Кнопки наушников

| Действие | Что происходит |
|---|---|
| 1 нажатие | пауза / продолжить |
| 2 нажатия | следующая глава |
| 3 нажатия | предыдущая глава (если прошло больше 3 с от начала главы — в начало текущей) |
| долгое нажатие | следующая глава |
| кнопка «Next» / «Previous» (на Bluetooth-наушниках) | следующая / предыдущая глава |

Главы берутся из файла: MP4/M4V/MOV (Nero `chpl` и дорожка глав QuickTime), MKV/WebM.
Если глав нет или идёт последняя глава — «следующая глава» включает следующее видео в папке;
если это последнее видео — текущее начинается сначала.

Важно: на многих телефонах долгое нажатие единственной кнопки гарнитуры система забирает
под голосового ассистента. Тогда до плеера оно не доходит — используйте двойное нажатие.
Что именно пришло от гарнитуры, видно в логах (строки `BG/Service key ...` и `BG/HeadsetButton`).

## Как собрать APK (GitHub Actions)

Репозиторий: https://github.com/krat1984/BGplayer

1. Любой push в репозиторий запускает сборку: вкладка **Actions** → **Build APK** (≈5 мин).
2. Внизу страницы запуска в разделе **Artifacts** скачайте `BGplayer-apk` (zip с файлом `.apk`).
3. Перекиньте APK на телефон и установите (разрешите установку из неизвестных источников).

Каждый запуск сначала прогоняет тесты. Если тест упал — APK не соберётся, отчёт лежит в артефакте `test-reports`.

### Ключ подписи

Все сборки подписаны одним ключом, поэтому новая версия ставится поверх старой с сохранением настроек.
Ключ **не хранится в репозитории** (он публичный): CI берёт его из секрета `BG_KEYSTORE_BASE64`
(Settings → Secrets and variables → Actions). Оригинал ключа — `app/bgplayer.keystore` в локальной папке
(в git не попадает). Не теряйте его: без него новые сборки не встанут поверх установленной версии.
Если секрет не задан, сборка всё равно пройдёт, но с временным ключом (в логе будет предупреждение).

## Логи

Экран **Логи** (кнопка вверху плеера):
- уровень логирования (по умолчанию VERBOSE — максимум), сохраняется между запусками;
- просмотр последних записей;
- «Отправить» — выгрузить все логи файлом (мессенджер, почта, диск);
- «Очистить».

Логи пишутся в файл (до 3 файлов по 1 МБ) и в logcat с префиксом тега `BG/`.
Если что-то работает не так — пришлите файл из «Отправить».

## Устройство проекта

- `app/src/main/java/com/bgplayer/core/` — логика без Android (покрыта тестами):
  `Mp4ChapterParser`, `MkvChapterParser`, `ChapterNavigator`, `HeadsetButtonDetector`, `SleepTimer`, `BgLog`.
- `app/src/main/java/com/bgplayer/app/` — Android: `PlaybackService` (Media3, фон, кнопки), `PlayerActivity`, `LogsActivity`, `Prefs`.
- `app/src/test/` — тесты; в `resources/` реальные маленькие видео с главами, сделанные ffmpeg.

Настройки версионированы (`Prefs.SCHEMA`): если формат меняется, старые значения отбрасываются.
Главы между запусками не кешируются.

### Тестовые файлы

Сгенерированы так (`meta.txt` — ffmetadata с тремя главами: 0 с «Вступление», 2 с «Chapter Two», 5 с «Финал»):
```
ffmpeg -f lavfi -i testsrc=size=64x48:rate=5:duration=8 -f lavfi -i sine=frequency=440:duration=8:sample_rate=8000 \
  -i meta.txt -map 0 -map 1 -map_chapters 2 -c:v libx264 -preset ultrafast -crf 45 -c:a aac -b:a 16k chapters_both.mp4
# chapters_qt.mp4: + -movflags disable_chpl; chapters_faststart.mp4: + -movflags +faststart; .mkv / .webm — та же команда
```
